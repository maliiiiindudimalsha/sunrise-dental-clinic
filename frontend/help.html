Help & Instructions

Step-by-step guidance for using the Sunrise Dental Clinic system.

How do I register a new appointment? +
Open Register Appointment. Enter the patient's name, contact number and address. Select a dentist and treatment, choose the date and time, then click Register Appointment. A unique appointment number will be generated automatically.
How do I view or update an appointment? +
Open Search / Update and select an appointment from the dropdown. Edit the patient details, date or time and click Save Changes.
How do I cancel an appointment? +
Select the appointment from Search / Update and click Cancel Appointment. Cancelled appointments remain stored for record keeping.
How do I generate a bill? +
Open Billing & Receipt, select an appointment and click Generate Bill. The receipt will appear automatically. Click Print Receipt to print it.
How do I send an appointment reminder? +
Open Notifications, select an appointment, choose SMS or Email, check the reminder message and click Send Notification.
Manage dentists and treatments ADMIN +
Open Manage Dentists to add, edit or delete dentists, treatments and consultation fees.
Manage staff accounts ADMIN +
Open Manage Staff to add staff accounts, change roles, reset passwords and activate or deactivate accounts.
How do I view reports? ADMIN +
Open Reports & Analytics. Select the date range and optionally a dentist, then click Generate Report to view appointments, revenue and other clinic statistics.
What should I do if there is a connection error? +
Check that the Java backend server is running and MySQL is started in XAMPP. Refresh the page and try again.
How do I safely exit the system? +
Click Log Out at the bottom of the sidebar. Your session will be closed and you will return to the login page.
